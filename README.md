# 🍅 Pomodoro Timer — Python Tkinter Project

A simple **Pomodoro Technique timer** built with Python and Tkinter as a practical exercise in creating graphical user interface (GUI) applications.

This project focuses on learning how to build an interactive desktop application, manage timer logic, and connect user interface elements to Python code.

---

## 🎯 About the Project

The Pomodoro Technique is a time-management method that alternates focused work sessions with short breaks. After several work sessions, a longer break is typically taken.

The goal of this project is to create a timer that helps users follow this cycle through a graphical interface.

As a study project, the main focus is on practicing **Tkinter**, event handling, and updating GUI elements over time.

## 🎮 How to Use

1. Run `main.py`.
2. The timer window opens and displays the current session.
3. Click **Start** to begin the countdown.
4. Work until the timer finishes.
5. Take the suggested break when the timer switches sessions.
6. Continue through the work and break cycles.
7. Use **Reset** to restart the timer when needed.

The exact controls and behavior may change during development.

---

## 🍅 The Pomodoro Cycle

A common Pomodoro schedule uses:

| Session | Duration |
|---|---:|
| Work | 25 minutes |
| Short break | 5 minutes |
| Long break | 20 minutes |

A longer break is generally taken after four completed work sessions.

These durations can be adjusted in the code as the project develops.
